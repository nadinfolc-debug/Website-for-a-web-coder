# NP.AI

Сайт-портфолио Надежды Приколота.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## React Bits Pro

В `components.json` уже подключены registries `@reactbits-starter` и `@reactbits-pro`.

1. Впишите ключ в `.env.local`:

```
REACTBITS_LICENSE_KEY=ваш-ключ
```

2. Установите официальный Ghost Type:

```bash
npx shadcn@latest add @reactbits-starter/ghost-type-tw --overwrite
```
